# Каталог материалов — Telegram Mini App

Справочник материалов (ЛДСП, МДФ, МДФ UV, Фанера, ДВП, ДСП, ХДФ, ламинированный гипсокартон)
с сайта em-c.kz — без цен и остатков, только название, категория и фото. Клиент может
искать, фильтровать по категории и сохранять материалы в избранное.

## Структура репозитория

```
em-c-catalog-bot/
├── index.html                      # сама мини-аппка (открывается через Telegram)
├── data/materials.json             # каталог (название, категория, фото, ссылка)
├── scraper/scrape.py               # скрипт сбора данных с em-c.kz
└── .github/workflows/update-catalog.yml   # автообновление каталога по расписанию
```

Сейчас в `data/materials.json` лежит небольшой пример (7 позиций) — для проверки,
что всё отображается. Полный каталог (~380+ позиций по всем категориям) появится
после первого запуска скрапера (см. ниже).

## Важный нюанс по «артикулу»

На em-c.kz нет отдельного видимого клиенту поля «Артикул» в карточке товара —
код/коллекция уже зашиты в самом названии (например «ЛДСП BLUE SKY (Голубое небо) (ЕМС)»
или «MDF UV DESIGN 2400*1200*9 ZH-B115»). Поэтому в приложении в качестве
кода-идентификатора используется само название товара — менеджер по нему сразу
узнает позицию. Внутренний технический `id` (латиницей, из URL) тоже сохранён в
`materials.json` — на случай, если понадобится точное сопоставление.

## Как задеплоить

### 1. Репозиторий на GitHub
Готово — репозиторий уже создан.

### 2. Включить GitHub Pages
Settings → Pages → Source → **Deploy from a branch** → ветка `main`, папка `/ (root)`.
Через пару минут приложение будет доступно по адресу вида:
`https://<ваш-логин>.github.io/em-c-catalog-bot/`

### 3. Настроить автообновление каталога
Workflow `.github/workflows/update-catalog.yml` уже настроен на запуск раз в день
(в 03:00 UTC) и ручной запуск. Ничего дополнительно включать не нужно — Actions
работают из коробки на публичных репозиториях.
Чтобы прогнать сразу: вкладка **Actions** → workflow «Обновление каталога em-c.kz» →
**Run workflow**.

Если хотите чаще/реже — поменяйте `cron` в файле workflow.

### 4. Подключить Telegram-бота
У вас уже есть токен бота (черновой, будет заменён позже) — **не коммитьте его в
репозиторий**, если репозиторий публичный. Токен нужен только для настройки кнопки
в @BotFather, хранить его в коде мини-аппки не требуется вообще — сама страница
токен не использует.

Шаги в @BotFather:
1. `/mybots` → выбрать бота → **Bot Settings** → **Menu Button** → **Configure Menu Button**.
2. Указать URL вашего GitHub Pages (из шага 2) и текст кнопки, например «Каталог».

Теперь у бота внизу появится кнопка, открывающая каталог как Mini App.

Когда переедете на «боевого» бота — просто повторите этот шаг с новым токеном,
код приложения менять не нужно.

### 5. (опционально) HTTPS свой домен
GitHub Pages уже отдаёт HTTPS из коробки — Telegram Mini Apps требуют именно HTTPS,
так что дополнительно ничего настраивать не нужно.

## Как работает избранное

Избранное хранится через `Telegram.WebApp.CloudStorage` — данные привязаны к
конкретному пользователю Telegram и синхронизируются между его устройствами без
отдельного бэкенда. Если открыть страницу вне Telegram (просто в браузере для
теста), избранное сохранится в `localStorage` браузера.

## Ручной запуск скрапера локально

```bash
cd scraper
pip install requests beautifulsoup4
python scrape.py
```

Обновит `../data/materials.json`.
